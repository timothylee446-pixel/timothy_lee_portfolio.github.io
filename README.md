# Timothy Lee portfolio

Static site: plain HTML, CSS, and a little JavaScript. No build tools needed to host it.

- `build.py` regenerates every page from the content inside it (run `python3 build.py`).
- Put photos in `images/` and videos in `videos/` using the file names shown on the page.
  A dashed box labeled "Add file: name" marks anything still missing.
- To host: drag this whole folder onto https://app.netlify.com/drop
