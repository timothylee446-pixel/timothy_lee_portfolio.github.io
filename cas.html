CAS

A contamination-aware sampling robot that takes water samples, then cleans its sampling tool and verifies that it is clean.

Status
Ongoing
Type
Venture group project
IP

Skills

CAS (contamination-aware sampling) is a venture group project with a patent pending. The objective is a robot that takes water samples, then cleans the sampling tool and verifies that it is clean before the next sample.

The system has three main parts:

  • A central robot arm
  • A sample rack
  • A decontamination station

Decontamination station

The decontamination station cleans the sampling tool after each sample and checks that it is clean.
